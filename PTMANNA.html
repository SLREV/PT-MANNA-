Koneksi Google Spreadsheet

Hubungkan aplikasi ke Google Sheets melalui Google Apps Script Web App
Salin URL hasil deploy Web App. Jika dikosongkan, data tetap tersimpan lokal di browser ini dan bisa di-export CSV.

Cara Setup Google Sheets (5 Langkah)

Sekali setup, langsung terhubung
  1. Buka Google Sheets — buat spreadsheet baru (misal: Data PT MANNA).
  2. Buka Extensions → Apps Script di menu spreadsheet.
  3. Salin isi file Code.gs (disediakan bersama aplikasi ini) ke editor Apps Script, lalu simpan.
  4. Deploy → New deployment → Web app. Atur Execute as: Me, Who has access: Anyone. Klik Deploy.
  5. Salin URL Web App ke kolom di atas, klik "Simpan & Uji Koneksi". Selesai! 🎉
