Pasang di PC & Android

Jadikan aplikasi dengan ikon sendiri
  1. PC (Chrome/Edge): buka alamat server → klik ikon Install di address bar, atau tombol Install Aplikasi di menu.
  2. Android (Chrome): buka alamat server dari HP → menu ⋮ → Install app / Tambahkan ke layar utama.
  3. HP satu WiFi dengan PC: pakai alamat http://IP-PC:3000 di kiri.
  4. Dari mana saja (internet): jalankan start-online.bat untuk mendapat alamat https publik (lihat README).

Cloud — Google Sheets

Semua data otomatis dicadangkan & tersinkron ke Google Spreadsheet
-
Cara setup Google Sheets (5 langkah)
  1. Buat Google Spreadsheet baru (misal: Data PT MANNA).
  2. Menu Extensions → Apps Script. Hapus isi editor, lalu tempel isi file cloud/Code.gs. Isi SECRET_KEY bila ingin lebih aman. Simpan.
  3. Deploy → New deployment → Web app. Execute as: Me, Who has access: Anyone. Klik Deploy & izinkan akses.
  4. Salin Web app URL (berakhiran /exec) ke kolom di atas, isi kunci rahasia yang sama.
  5. Klik Simpan & Uji Koneksi. Selesai! 🎉 Sheet Data PO, Surat Jalan, Invois, Penawaran, Keuangan akan terisi otomatis.
